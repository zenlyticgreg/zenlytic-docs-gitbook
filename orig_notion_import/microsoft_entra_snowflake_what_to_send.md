# Entra-Snowflake: What to Send to Zenlytic

This document outlines the information you need to send to Zenlytic to complete the Entra-Snowflake integration setup.

## Required Information

After completing the setup in both Snowflake and Microsoft Entra, you'll need to provide the following information to Zenlytic:

### From Snowflake
1. OAuth Client ID
2. OAuth Client Secret
3. OAuth Token URL
4. OAuth Authorization URL

### From Microsoft Entra
1. Application (Client) ID
2. Client Secret
3. Directory (Tenant) ID

## How to Send

Please send this information to your Zenlytic contact or to support@zenlytic.com. Make sure to:
1. Include all the required information listed above
2. Reference that this is for the Entra-Snowflake integration
3. Specify if this is for a development or production environment

## Security Notes

- All credentials should be sent through secure channels
- Do not share these credentials in public forums or documentation
- Consider using a password manager or secure file sharing service to transmit the information

## Next Steps

After sending the information:
1. Zenlytic will configure the integration on our end
2. We'll provide you with confirmation once the setup is complete
3. You can then test the integration by attempting to connect to Snowflake through Zenlytic
